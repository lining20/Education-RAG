# 8200 资料导入页视觉改版

本版以主工作区现有 `page/index.html` 为基线，只调整 HTML 展示结构和内联 CSS；在独立前端 worktree 开发，不写入后端工作区，不修改后端模块、配置或接口。

## 视觉调整

- 深色侧栏、蓝色操作按钮、浅灰工作区、统一的图标与组件层级。
- 左侧上传面板将内容类型/文件选择与归属信息并排，右侧为任务进度与批次恢复。
- 桌面外层固定为 `100dvh`，没有页面右侧整体纵向滚动；底部提交按钮及批次恢复入口固定留在各自面板中。表单展开长说明、任务过多或展开详情时，内容仅在所属面板内滚动。
- 700px 以下小屏采用纵向排布，保证控件可访问；手机高度不足时允许正常页面滚动。
- 文件打包规范改为可展开说明，文本完整保留；没有增加拖放上传或其他未实现能力。

## 功能保持

原页面的可执行 `<script>` 内容逐字一致。四种必选内容类型、原生多文件选择、ZIP、200 MiB 校验、全部归属输入、POST FormData、批次轮询、进度统计、详情耗时、localStorage 恢复与异常提示均沿用当前代码。

静态对比检查通过：所有原表单/输入/按钮的标签及属性完全相同，原有 ID 全部保留且无重复，HTML 标签配对正确，JavaScript 语法检查通过。脚本 SHA-256 见随提交说明。

应用户明确要求，本轮未执行浏览器预览或截图验证；桌面视觉和实际滚动行为仍应在部署后人工确认。

独立 worktree 不包含后端工作区当前未提交的 API 和节点文件。合入时只使用本分支的 `page/index.html` 即可由现有 8200 服务提供新版界面；不要用本 worktree 的旧后端代码覆盖正在开发的后端。
